# Uniswap V2, V3 і V4: як контракт перевіряє оплату

Матеріали пояснюють одну ідею: **Uniswap може видати токени до остаточного розрахунку, але перед успішним завершенням перевіряє, чи виконані всі зобов’язання.** У V2, V3 та V4 ця перевірка влаштована по-різному.

У комплекті є шість слайдів, текст виступу з цільовою тривалістю п’ять хвилин і пояснення для підготовки до технічних запитань.

**[Відкрити презентацію онлайн](https://ermolz.github.io/uniswap-architecture/)** · [Відкрити файл презентації](presentation.html)

## З чого почати

1. Прочитати [нотатки для підготовки](07-personal-notes.md): головна думка, підказка до кожного слайда і три короткі приклади. Наприкінці є маршрут на 15–20 хвилин.
2. Якщо незрозумілі callback, tick або дельта, відкрити [навчальний посібник](02-learning-guide.md). Він пояснює терміни та порядок дій без построкового розбору коду.
3. Відкрити презентацію поруч із [текстом виступу](03-speech.md) та проговорити його вголос із секундоміром. Позначки часу — цілі для репетиції; фактичну тривалість потрібно виміряти.
4. Перевірити себе за [питаннями до захисту](04-defense-preparation.md). Для доказів у коді перейти до звіту; для складніших обчислень — до поглибленого розбору.

## Як показати презентацію

Відкрити `presentation.html` подвійним клацанням у сучасному Chrome або Edge. Сервер, Node.js і встановлення пакетів для перегляду не потрібні. **Потрібен інтернет для завантаження Tailwind CSS із CDN і шрифту Manrope**, а також відкриття зовнішніх джерел. Якщо шрифт недоступний, використовується системний. Кеш браузера не є надійною офлайн-версією.

| Дія | Керування |
|---|---|
| Наступний слайд | Кнопка «Далі», → або Space |
| Попередній слайд | Кнопка «Назад» або ← |
| Перший / останній слайд | Home / End |
| Будь-який слайд на широкому екрані | Шість індикаторів у центрі панелі керування |
| Повноекранний режим | Кнопка на панелі або F; Esc — вихід |
| Посилання на конкретний слайд | Фрагмент адреси `#slide-1` … `#slide-6` |

Коли фокус на кнопці чи посиланні, Space виконує дію цього елемента. Це запобігає подвійному перемиканню. Автоматичного перегортання немає. Перед захистом перевірити завантаження стилів і читабельність на екрані показу.

## Публікація

GitHub Pages публікує корінь гілки `main`. Файл `index.html` відкриває `presentation.html`, зберігаючи посилання на слайд; `.nojekyll` вимикає обробку Jekyll. Після надсилання змін у `main` GitHub автоматично оновлює сайт. Основний файл презентації — `presentation.html`.

## Межі аналізу

Досліджено офіційний код на конкретних SHA — ідентифікаторах комітів із [реєстру джерел](05-sources.md). Це не перевірка певного розгортання в мережі й не повний аудит безпеки. Приклади використовують умовні суми в мінімальних одиницях токенів; транзакції не надсилаються.

Виконувані тести контрактів і числові вимірювання витрат газу до комплекту не входять. Ручні сценарії показують конкретні умови успіху та відкату. Пояснення витрат газу описують механізми, а не гарантують однакову економію для будь-якого маршруту.
