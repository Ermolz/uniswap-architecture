## Як опрацювати комплект

1. Прочитати навчальний посібник: спочатку модель викликів і відкату, потім V2, V3 та V4.
2. Опрацювати технічний звіт, відкриваючи GitHub-посилання біля фрагментів. Зіставляти коментар із конкретною операцією, а не лише з назвою функції.
3. Самостійно повторити три ручні сценарії та відповісти на 12 питань без підглядання.
4. Відкрити презентацію та прочитати текст виступу вголос із секундоміром. Позначки часу є цільовими: фактичну тривалість визначає темп мовлення.
5. Сформулювати пояснення рядків власними словами відповідно до вимоги завдання про власноруч написані коментарі. Надані пояснення є матеріалом для опрацювання; сам факт їх наявності не підтверджує особистого авторства студента.

Для здачі можна використати **технічний звіт окремо**: він містить необхідні докази та посилання. Посібник і питання призначені для підготовки; текст виступу — для репетиції.

## Як показати презентацію

Відкрити `presentation.html` подвійним клацанням у сучасному Chrome або Edge. Сервер, Node.js і встановлення пакетів для перегляду не потрібні. **Потрібен інтернет для завантаження Tailwind CSS із CDN і шрифту Manrope**, а також відкриття зовнішніх джерел. Якщо шрифт недоступний, використовується системний. Не слід покладатися на кеш браузера як на офлайн-версію.

| Дія | Керування |
|---|---|
| Наступний слайд | Кнопка «Далі», → або Space |
| Попередній слайд | Кнопка «Назад» або ← |
| Перший / останній слайд | Home / End |
| Будь-який слайд на широкому екрані | Шість індикаторів у центрі панелі керування |
| Повноекранний режим | Кнопка на панелі або F; Esc — вихід |
| Посилання на конкретний слайд | Фрагмент адреси `#slide-1` … `#slide-6` |

Під час фокусу на кнопці чи посиланні Space виконує стандартну дію цього елемента, щоб уникнути подвійного перемикання. Автоматичного перегортання немає. Перед захистом перевірити завантаження стилів і читабельність на екрані показу.

## Публікація

GitHub Pages публікує корінь гілки `main`. Файл `index.html` відкриває `presentation.html`, зберігаючи посилання на слайд; `.nojekyll` вимикає обробку Jekyll. Після надсилання змін у `main` GitHub автоматично оновлює сайт. Основний файл презентації — `presentation.html`.

## Межі аналізу

Досліджено офіційні вихідні тексти на конкретних SHA, наведених у реєстрі. Це не перевірка відповідності певному розгортанню в мережі й не повний аудит безпеки. Приклади використовують умовні суми в мінімальних одиницях токенів; транзакції не надсилаються.

Виконувані тести контрактів і числові газові бенчмарки до комплекту не входять. Ручні сценарії демонструють конкретні умови успіху та відкату. Висновки про газ пояснюють механізми витрат, а не гарантують однакову економію для будь-якого маршруту.
